# 📖 NovelReader · 本地小说阅读器（个人练手项目）

> 一个基于 Python + 原生 JavaScript 的本地 Markdown 小说阅读工具，支持目录浏览、搜索筛选、阅读进度追踪，并集成了离线 TTS 语音合成（Sherpa-ONNX）。  
> **仅供个人本地自用学习，请勿用于商业或生产环境。**

---

## ✨ 主要功能

| 功能 | 说明 |
|------|------|
| 📂 文件树 | 自动扫描 `chapters/` 目录，支持文件夹折叠/展开 |
| 🔍 搜索与筛选 | 全文搜索，按作者/标签筛选章节 |
| 📊 阅读进度 | 滚动位置自动保存，侧边栏显示百分比 |
| 🔊 离线 TTS | 基于 Sherpa-ONNX 的中文语音朗读，支持速度调节、暂停/继续、长按选句从该句开始 |
| 🧠 相似推荐 | 基于标签 Jaccard 相似度的章节推荐 |
| 🎨 暗色主题 | 一键切换，设置自动保存 |

---

## 🧱 技术栈

- **后端**：Python 3.8+，`http.server` 多线程，SSE 流式推送 TTS 音频
- **前端**：纯原生 HTML/CSS/JavaScript，无第三方框架
- **语音合成**：Sherpa-ONNX（离线中文模型）
- **数据存储**：本地 JSON 文件（阅读状态、元数据缓存）

---

## 🚀 快速开始

```bash
# 安装依赖
pip install sherpa-onnx soundfile numpy

# 将小说 .md 文件放入 chapters/ 目录（支持子文件夹）
# 可选在文件头部添加元数据：
# - 作者：刘慈欣
# - 标签：科幻，经典

# 启动服务
python main.py

---
## ⚙️ 主要配置（config.py）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 8080 | 服务端口 |
| `CHAPTERS_DIR` | `'chapters'` | 小说存放目录 |
| `PRELOAD_TTS` | `True` | 启动时是否预加载 TTS 引擎 |
| `LOG_LEVEL` | `'INFO'` | 日志级别 |
